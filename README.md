# AlphaTab Open Source Projects

Welcome to my public-facing repository! This workspace is used for managing and showcasing my public projects which i think are important.

## 🚀 Projects

### [AutoApply](./AutoApply/)
**Automated AI Job Assistant**
AutoApply is a personal assistant designed to save you hundreds of hours of scrolling through LinkedIn. It automatically finds jobs, filters out irrelevant ones, and uses AI to score the remaining positions against your specific resume to find the perfect match.

---

### [ShortsForge (V2 Autopilot)](./shortsforge-platform/)
**A Fully Automated, Headless YouTube Shorts Factory**
ShortsForge is an autonomous video generation pipeline. It scrapes content, rewrites and translates it using AI, generates audio, builds dynamic visual scenes (including Playwright-rendered infographics), and uploads directly to YouTube via OAuth—all without human intervention.
